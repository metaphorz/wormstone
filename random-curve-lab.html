How the curve works

r(θ) = R [1 + Σ aₖ cos(kθ + φₖ)]
x = r(θ) cos θ,   y = r(θ) sin θ;   0 ≤ θ ≤ 2π.

The seed generates a random weight qₖ between 0.2 and 1 and a phase φₖ between 0 and 2π for each harmonic. We set wₖ = qₖ / kᵖ and aₖ = ε wₖ / Σwⱼ. Consequently, Σ|aₖ| = ε < 1 and the radius is always positive. R is the angular mean radius, not the area-equivalent radius.

Try increasing irregularity, reducing smoothness, then adding harmonics. Higher smoothness suppresses fine ripples. Changing a control preserves the seed’s underlying weights and phases. The dashed circle has radius R; the plot scale stays fixed so size changes remain visible.

The curve closes with matching derivatives. It is star-shaped about the origin, which need not be its area centroid. The displayed radius range is sampled numerically. Units are arbitrary. To use another center, add cₓ and cᵧ to x and y.
